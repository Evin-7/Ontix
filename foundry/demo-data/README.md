# Fictional Foundry demo data

These six CSVs contain fictional enterprise records and `example.com` email addresses. They are source fixtures for the Ontix Foundry demo; they are not production data and do not create Foundry resources by themselves.

Upload each file as a dataset in the Foundry `ontix` project. The rows use stable IDs so the configured Ontology can map each `*Id` column to its corresponding object primary key.

Import order: `Customers.csv`, `Projects.csv`, `Teams.csv`, `Employees.csv`, `OperationalCases.csv`, then `ApprovalRequests.csv`.
